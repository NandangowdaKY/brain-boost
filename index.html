04 / Project Documentation

Project Objectives & Team Members

BrainBoost combines Biology and Computer Science to demonstrate how neural memory concepts connect with interactive web development.

Core Objectives

  • Study the anatomical structure and cognitive functions of the human brain.
  • Understand electrochemical neuron communication and synaptic memory formation.
  • Create an accessible educational website explaining brain health fundamentals.
  • Develop interactive memory exercises using HTML, CSS, and JavaScript.
  • Provide Number Memory, Pattern Matrix, and Card Matching training modules.
  • Calculate game scores accurately and display real-time user performance.
